# code-reader

カメラでQRコード・バーコードを読み取り、kintoneレコードの指定フィールドへ書き込むkintoneプラグインです。

## 特長

- QRコード（[jsQR](https://github.com/cozmo/jsQR)）と各種バーコード（[Quagga2](https://github.com/ericblade/quagga2)）に対応。バーコードはCODE39/CODE128/EAN-13/EAN-8/UPC-A/UPC-E/Codabar(NW-7)/ITF/CODE93から複数選択可
- 書き込み先フィールドコードはプラグイン設定画面から指定でき、コード修正なしに複数アプリへ再利用できる
- 1つのコードに複数の値が含まれる場合、区切り文字（カンマ・セミコロン・ハイフン等のプリセットまたは自由入力）または桁数（文字数）で分割し、複数フィールドへ順番に書き込める
- 書き込み先がルックアップフィールドの場合、参照先アプリからの値の自動取得（取得ボタンを押した状態）まで行う
- カメラの前面/背面優先を設定画面で切り替え可能（PC内蔵カメラでのテスト・デモにも対応）
- カメラ映像・確認ダイアログはkintoneのUI（`kintone.createDialog` / `kintone.mobile.createBottomSheet`）を使用し、kintone標準画面と統一感のある見た目にしている
- PC・モバイル両対応

## 動作イメージ

1. レコード追加・編集画面のヘッダーに表示される「QRコードをスキャン」「バーコードをスキャン」ボタンを押す
2. カメラダイアログが開き、コードを読み取る
3. 確認ダイアログで読み取り結果を表示（OKで確定 / 再取得でやり直し）
4. 設定した文字列フィールドへ読み取り結果を書き込む

より実践的な利用例（複数フィールドへの装置ID入力、着手/完了打刻ワークフロー）は [`examples/start-completion-sample`](./examples/start-completion-sample) を参照してください。

## セットアップ

### 1. 依存ライブラリ

jsQR・Quagga2 はCDN経由で読み込むため、追加のインストールは不要です。

### 2. パッケージング

[`@kintone/cli`](https://cli.kintone.dev/) を使用します。

```bash
npm install -g @kintone/cli
cd plugins/code-reader
npm run keygen  # 初回のみ: 署名鍵(private.ppk)を生成
npm run pack
```

`private.ppk` は `.gitignore` 対象のため、生成後は安全な場所に保管してください（同じ鍵を使わないとプラグインの更新アップロードができません）。

### 3. kintoneへの読み込み

「kintoneシステム管理」→「プラグイン」→「読み込む」から `dist/plugin.zip` をアップロードし、対象アプリに追加します。

### 4. プラグイン設定

対象アプリの「プラグインの設定」画面で、以下を設定します。

- 読み取るコード種別（QRコード / バーコード）
- バーコードを有効にした場合、対応する規格（複数選択可）
- カメラの向き（背面優先 / 前面優先）
- 読み取り結果の分割方法（分割しない / 区切り文字で分割 / 桁数で分割）
- 書き込み先フィールドコード（複数指定可。分割方法に応じて上から順に書き込まれる）
