# reminder-notify 個別仕様

全体共通の開発方針は [ルートのCLAUDE.md](../../CLAUDE.md) を参照。ここには本カスタマイズ固有の仕様のみを記載する。GAS側の仕様は [gas/README.md](./gas/README.md) を参照。

## 機能概要

「納期」「何日前に送るか」「送信時刻」から送信予定日時を自動算出し、kintone側でレコードを準備する。実際のメール送信はGoogle Apps Script（[gas/](./gas/)）が時間主導型トリガーで定期的にkintone REST APIを確認し、送信予定日時になったレコードに対して行う。kintone側カスタマイズは以下を担当する。

- 送信予定日時の自動算出
- 保存時のバリデーション（送信先1件以上、日時算出エラー）
- レコード詳細画面からの即時送信リクエスト登録

## 対象アプリのフィールドコード（固定）

本カスタマイズは、複数アプリでの再利用よりもシンプルさを優先し、フィールドコードを`src/desktop.js`の`FIELD`定数に固定値として持つ。対象アプリは、以下のフィールドコードで作成する必要がある（GAS側`gas/src/Config.js`の`FIELD`定数も同じ値で定義しており、両者は必ず一致させること）。

| フィールドコード            | 型                                | 説明                                                     |
| --------------------------- | --------------------------------- | -------------------------------------------------------- |
| `Title`                     | 文字列（1行）                     | タイトル                                                 |
| `Deadline`                  | 日付                              | 納期                                                     |
| `DaysBefore`                | 数値                              | 何日前に送るか                                           |
| `SendTime`                  | 時刻                              | 送信時刻                                                 |
| `ScheduledSendAt`           | 日時                              | 送信予定日時（自動算出）                                 |
| `MailSubject`               | 文字列（1行）                     | メール件名                                               |
| `MailBody`                  | 文字列（複数行）                  | メール本文                                               |
| `SendStatus`                | 文字列（1行）またはドロップダウン | 送信ステータス（未送信/送信処理中/送信済み/エラー/停止） |
| `SendRequest`               | チェックボックス                  | 即時送信要求                                             |
| `SentAt`                    | 日時                              | 送信日時                                                 |
| `ErrorMessage`              | 文字列（複数行）                  | エラーメッセージ                                         |
| `SendCount`                 | 数値                              | 送信回数                                                 |
| `Recipients`                | テーブル                          | 送信先一覧                                               |
| `Recipients.RecipientCode`  | 文字列（1行）または Lookup        | 送信先コード                                             |
| `Recipients.RecipientName`  | 文字列（1行）または Lookup        | 送信先名                                                 |
| `Recipients.RecipientEmail` | 文字列（1行）または Lookup        | 送信先メールアドレス                                     |
| `Recipients.RecipientType`  | ドロップダウン（`TO`/`CC`/`BCC`） | 送信区分                                                 |

送信先名・送信先メールアドレスは、別アプリ（送信先マスタ等）からのLookupフィールドとして構成しても問題ない。`record[フィールドコード].value`で値を参照するだけなので、通常の文字列フィールドかLookupフィールドかを区別しない。

ステータス文言（未送信/送信処理中/送信済み/エラー/停止）と即時送信要求の値（`即時送信`）も`desktop.js`内の固定値。

## 送信ステータスの状態遷移

```
未送信 → (GASが送信予定日時到来を検知/即時送信要求) → 送信処理中 → 送信済み
                                                                  ↘ エラー
```

- 送信処理中のレコードは編集不可（`app.record.edit.submit`でエラーにする）
- 送信済み・エラーのレコードを編集して保存すると、未送信に戻り再度送信対象になる
- 停止は、GAS側の対象抽出条件から除外するための状態（手動で設定する想定。UIからの遷移は持たない）

## APIリクエスト数について

- kintone側カスタマイズ自体は、即時送信ボタン押下時にレコード更新PUTを1回発行するのみ
- GAS側の定期実行によるREST API呼び出し回数は [gas/README.md](./gas/README.md) を参照
